- 메인의 질의응답 영역: 패들렛 QR과 URL. https://padlet.com/modulabs/sk-s024asr5uhukjk7vh8h7
- 교안 94장은 실습 결과와 학습 포인트 복습, 96장은 감사·만족도 QR 및 2주 실천 탭입니다. 만족도 조사는 교육 종료 5분 전에 자리에서 함께 진행합니다.
- 개념 설명 17장에 생성 그림 11종과 비유를 넣었습니다. 실습 프롬프트와 96장 순서는 유지합니다.
- 최종 웹 교안은 공통 디자인시스템으로 제목·본문·카드·프롬프트·표를 통일했습니다. 본문 상한20px, 내용이 많은 상태18–20px. 96장/모든 상태의 실제 글자 경계를 확인합니다.
- `review.html`: 짧은 설명·관계·검색·분야 필터·목록 보기로 복습하는 별도 그래프. 기존 슬라이드는 수정하지 않습니다. 원본은 `_workspace/review-graph.html`.
- `slides.html`: 교안96장 · 본편96장 + 선택0장(강사 노트는 공개판에서 제외)
- 최신 96장 교안은 웹에서 열고 탭·복사 버튼을 사용합니다. 기존 PDF는 재생성하지 않고 복습용 다운로드로 유지합니다.
- `reference.html`, `skills.html`: IA·PRD 개념과 전체 스킬 복사
- 별도 실습자료 ZIP은 제공하지 않습니다. 스킬은 교안에서 복사하고, 가상 CSV와 메모는 실습 중 만듭니다.

GitHub Pages는 `main` 브랜치 루트에서 게시합니다. `.nojekyll`을 유지합니다.
교안·핸드북 생성 원본과 강사용 자료는 교육 작업공간에서 따로 관리합니다.
갱신은 작업공간의 `_workspace/build_sk_gas_site.py`로 공개 파일을 생성한 뒤 이 저장소에 커밋·푸시합니다.
스킬 출처와 라이선스는 `LICENSES.md`를 참고합니다.
