실습 중 필요한 순간에 참고하는 두 자료입니다. 정답 앱·미리 작성한 프로젝트가 아닙니다.

참고1 · IA와 화면 흐름

IA는 어떤 화면에 어떤 정보·버튼을 두고 어디로 이동할지 정하는 지도입니다. 목표를 인터뷰한 뒤 화면과 이동을 먼저 읽고 확인합니다.

볼 것검토 질문
첫 화면사용자가 가장 먼저 무엇을 보나?
입력·동작무엇을 넣고 어떤 버튼을 누르나?
결과·이동결과를 어디서 읽고 어떻게 돌아가나?
빈 화면·오류기록이 없거나 실패하면 무엇을 보여 주나?

예: 퀴즈 시작 → 문제/응답 → 해설 → 결과. 이 예는 구조 설명이며 직접 만들 웹앱의 화면은 내 인터뷰 답변으로 정합니다.

참고2 · PRD와 완료 기준

PRD는 해결할 문제·사용자·핵심 기능·동작·저장·예외·완료 기준을 합의하는 제품 요구사항 문서입니다. IA를 읽고 동작과 정책을 더 질문해 구체화합니다. 흐름이 바뀌면 IA도 갱신합니다.

볼 것검토 질문
문제·범위누구의 어떤 불편을 이번에 해결하나?
동작·데이터입력하면 무엇이 바뀌고 무엇을 저장하나?
예외빈 입력·중복 입력·잘못된 값은 어떻게 처리하나?
완료 기준어떤 순서로 누르면 어떤 결과가 나와야 하나?

예: 답을 선택하면 해설을 표시하고 점수를 반영한다. 새로고침 뒤 보관해야 하는 데이터가 있다면 그 범위를 인터뷰로 정한다. 구현 전에 문서 조건 하나를 피드백하고 최종 프롬프트를 확인합니다.
